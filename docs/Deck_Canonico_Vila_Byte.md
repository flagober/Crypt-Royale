# Baralho de treino — Vila Byte

Versão de regras: 0.1.0

Este baralho usa monstros selvagens canônicos da região R1. Nexus não são tropas comuns: cada jogador terá um slot Nexus próprio quando essa mecânica for implementada.

| ID canônico | Carta | Custo | Papel na arena |
|---|---|---:|---|
| MC-0001 | Bit Bug | 2 | enxame de três unidades frágeis |
| MC-0004 | Data Mouse | 3 | atacante à distância |
| MC-0007 | Code Slime | 2 | dupla de pressão econômica |
| MC-0010 | Pixel Pup | 3 | lutador móvel e equilibrado |
| MC-0013 | Circuit Hare | 4 | investida rápida de alto dano |
| MC-0016 | Cache Crow | 3 | dupla voadora de alcance médio |
| MC-0019 | Byte Boar | 5 | tanque lento de muita vida |
| MC-0031 | Socket Crab | 4 | guardião resistente |

Os valores de batalha são próprios do modo Crypt Royale e permanecem data-driven. Eles não alteram nível, captura, atributos ou progressão do RPG MonsterCrypt.
